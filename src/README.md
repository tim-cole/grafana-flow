# Flow Diagrams for Grafana

Flow diagram visualization panel, designed for SIP capture / call-flow tooling such as [homer](https://sipcapture.org), [hepic](https://hepic.cloud), and [qryn](https://qryn.dev).

Requires Grafana >=12.3.0 (React 19). This is a fork of [metrico/grafana-flow](https://github.com/metrico/grafana-flow) maintained for continued Grafana/React compatibility.
